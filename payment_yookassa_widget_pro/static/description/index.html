Enterprise extension for YooKassa Payment Widget

What is YooKassa Widget Pro?

YooKassa Widget Pro extends the free YooKassa Payment Widget with enterprise features required by Russian businesses — 54-FZ fiscal receipts, automated completion receipts, and a full post-payment onboarding flow for new customers.

Requires: YooKassa Payment Widget (free base module).

Key Features

54-FZ prepayment receipt Sends a fiscal prepayment receipt to YooKassa at the moment of payment. Required for Russian merchants under Federal Law 54-FZ.
54-FZ completion receipt Sends a completion receipt after service delivery. Pulls line items from the sale order. Automated via daily cron.
Overdue receipt cron Daily cron automatically sends completion receipts for all transactions where service was delivered more than 45 days ago.
Email verification After payment, new customers receive a verification email. Token-based confirmation marks the partner as verified in Odoo.
Portal account creation First-time buyers are guided to set a password and create their Odoo portal account — no manual admin steps required.
Configurable onboarding flow Override _yk_onboarding_next_step() to redirect customers to any post-payment page — placement tests, dashboards, lesson portals.
Receipt transaction list Adds "54-FZ Receipt Sent" and "Receipt Date" columns to the payment transaction list view for easy auditing.

Configuration

  1. Install YooKassa Payment Widget (free base module) first
  2. Install YooKassa Widget Pro
  3. Go to Accounting → Configuration → Payment Providers → YooKassa
  4. Verify your Shop ID and Secret Key are set
  5. Completion receipts will be sent automatically by the daily cron
  6. To trigger manually: select transactions → Action → Send Completion Receipt
