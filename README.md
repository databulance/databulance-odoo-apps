# Databulance Odoo Apps

Custom Odoo 19 modules by [Databulance](https://databulance.com).

## Modules

### payment_yookassa_widget
YooKassa embedded checkout widget for Odoo 19.
Accept payments inline — no redirects.
- Embedded YooKassa widget
- Webhook processing
- Idempotent payment creation
- Basic receipt with VAT mapping

**License:** LGPL-3 · Free

---

### payment_yookassa_widget_pro
Enterprise extension for YooKassa Widget.
- 54-ФЗ completion receipts
- Email verification flow
- Portal account creation
- License key management

**License:** OPL-1 · €249

---

### booking_lance
Plug-and-play booking system for Odoo 19.
- Per-staff scheduling with auto slot generation
- Client portal booking flow
- Email confirmations + iCal
- REST API + webhooks
- Cancel/reschedule policies

**License:** LGPL-3 · Free
