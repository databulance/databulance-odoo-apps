YooKassa Payment Widget

Embedded checkout · No redirects · Odoo 19

Accept YooKassa payments directly on your Odoo website

What is this module?

YooKassa Payment Widget integrates the YooKassa embedded checkout widget into Odoo 19. Unlike redirect-based integrations, the payment form renders inline on your page — customers never leave your website. Works with Odoo e-commerce, custom payment flows, and any website built on Odoo.

Key Features

Embedded widget YooKassa checkout renders inline — no redirects, no popups. Customers pay without leaving your site.
Idempotent payments Safe retries — if a payment exists and is pending, the same token is reused. No duplicate charges.
Webhook processing Receives YooKassa event notifications at /payment/yookassa/webhook. Automatically updates transaction state.
Status sync On return from payment, syncs status directly from YooKassa API — no stale state.
Basic receipt Sends a basic prepayment receipt to YooKassa. Pulls line items from sale order when available.
VAT code mapping Automatically maps Odoo tax rates (20%, 10%, 0%) to YooKassa VAT codes.
Odoo 19 compatible Built specifically for Odoo 19. Correct MRO guards to avoid conflicts with other YooKassa modules.

Payment Flow

1

4
Odoo updated
Via webhook + return sync

Configuration

  1. Install the module
  2. Go to Accounting → Configuration → Payment Providers → YooKassa
  3. Enter your Shop ID and Secret Key from the YooKassa merchant dashboard
  4. Set the webhook URL in YooKassa dashboard: https://yourdomain.com/payment/yookassa/webhook
  5. Enable the provider and publish it on your website
